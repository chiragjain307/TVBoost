# I96 8K compatibility

| Item | Result |
|---|---|
| Verified build | `I96_8K-20251222-301SMSX300`, chip `Hi3798MV300`, SDK 28 |
| Launcher | Works. minSdk 26, no internet permission |
| Root | Not used |
| Other firmware for this model | Refused by the installer until it has its own test run |

Boxes sold under the same name can contain different hardware, which is why matching uses the firmware build
and the chip rather than the model name.
